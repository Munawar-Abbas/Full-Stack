# Bazaar Lane (Frontend + Backend)

bazaar-lane/
  backend/    NestJS (module, service, controller)
  frontend/   index.html, style.css, script.js

## Chalane ka tareeqa

1) Backend (pehle yeh):
     cd backend
     npm install
     npm run start:dev
   Jab "Backend running on http://localhost:3000" aa jaye, terminal khula rehne dein.

2) Frontend:
   frontend/index.html par double click karein (ya VS Code mein Live Server).

Data memory mein hai, backend restart par reset ho jata hai.
